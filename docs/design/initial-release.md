# 초기버전 완성 계획

갱신일: 2026-09-10. 사용자 목표는 **게임 초기버전 완성 도전**입니다. 승인된 장사 게임과 [후속 설계](after-first-market.md)를 실제 플레이로 연결합니다.

## 완성 범위

1. 기존 동네 장터의 첫 진입을 유지합니다. 수량 하나로 시작하며 다섯 영업을 완주할 수 있습니다.
2. 완주하면 목표 금액과 관계없이 공원 장터에 갈 수 있습니다. 산책 주간·공연 주간의 손님 구성과 재료비 흐름이 다르며, 재시도와 새로고침에서는 조건이 바뀌지 않습니다.
3. 준비금 목표를 처음 달성하면 간판·진열 공간이 바뀌고 다음 장터에도 남습니다. 설비 자리 하나를 보관 또는 새 메뉴에 배분하며 두 선택의 비용과 기회를 비교합니다. 운영 자금은 매번 6,000원입니다.
4. 공원 장터에서는 다음 날의 단체 주문을 선택할 수 있습니다. 예약 대금과 납품 의무, 일반 손님의 판매 기회를 구분하며 재시도·저장 시에도 보존합니다.
5. 장터 간 이동, 최고 기록, 성장, 감사·개발 중 스크롤을 연결합니다. 이전 저장을 읽으며 중도 초기화로 영구 기록을 지우지 않습니다.

첫 장터 → 다른 조건을 읽는 장터 → 내 가게의 변화 → 내일까지 보는 판단을 하나의 반복 루프로 만듭니다. 서버·로그인·랭킹·대출·투자·마을 이동은 이 버전의 범위가 아닙니다.

## 검증과 출시

- 돈·재고·손익·예약 의무 보존과 불가능한 주문 거절을 도메인 테스트로 확인합니다.
- 여러 가격·물량·설비·예약 전략을 비교합니다. 모든 조건에서 같은 선택이 이기는지 확인하고 준비 전에 판단 근거를 제공합니다.
- 기존 v1/v2 저장 이전, 새 저장 왕복, 손상·저장 불가, 재시도·영업 중 새로고침·연타를 확인합니다.
- PC와 모바일 390×844에서 처음부터 끝까지 플레이하고 주요 장면·모달·키보드·동작 감소·가로 넘침을 검증합니다.
- 문서를 실제 구현과 맞추고 `npm test`, `npm run build`, 브라우저 스모크를 통과한 버전을 main에 푸시한 뒤 공개 배포를 검증합니다.

실사용자 재미와 경제 이해는 자동 검증과 구별합니다. 기능을 연결한 뒤 사전 설명 없는 플레이 관찰로 재시도 동기와 놓친 단서를 수집하고 수정합니다. 관찰 없이 장기 숙련이나 학습 효과가 입증됐다고 주장하지 않습니다.
