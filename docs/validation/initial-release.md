## 실행

로컬 최종 검증은 규칙 테스트 28개, 빌드, PC·모바일 전체 브라우저 흐름을 통과했습니다. 수량 입력 직후 첫 클릭이 무시되는 문제를 재현해 수정했고, Tab 없이 가게 열기·도움말 클릭 및 실제 터치 이벤트의 첫 탭도 확인했습니다. 변경 문서 10개의 로컬 링크 45개를 확인했습니다.

```sh
npm test
npm run build
npm run preview -- --port 4173
npm run test:smoke
```

화면 캡처는 기본 `/tmp/good-afternoon-market-qa`에 저장합니다. `MARKET_TEST_URL`로 공개 배포를 같은 스모크에 넣을 수 있습니다. 배경 이미지 로딩, 콘솔·요청 실패와 가로 넘침을 함께 확인합니다.

## 개발자의 게임성 판단

첫 판의 조작은 수량 하나로 시작합니다. 다음 장소에서는 가족과 공연 관객의 다른 가격 반응, 비용이 오르거나 내려가는 시점, 설비 자리의 기회비용, 단체 판매와 일반 손님의 진열 여유가 다른 선택을 만들었습니다. 새 메뉴가 모든 조건에서 손해였던 초기 수치를 수정하고 산책객의 차 선호를 선택 전에 알리도록 했습니다.

이 판단과 최적 경로 계산은 실제 재미를 입증하지 않습니다. 세 고정 조건을 외우면 소진될 수 있고, 후반 준비 패널의 정보량도 실제 플레이로 확인해야 합니다. 조작·규칙이 완결된 초기버전과 장기 숙련·학습 효과 검증을 구분합니다.
