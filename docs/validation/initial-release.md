# 초기버전 검증 기록

갱신일: 2026-09-10. 구현 기준은 [초기버전 계획](../design/initial-release.md)입니다. 아래는 개발 환경 검증이며 실제 사용자 관찰 결과와 구분합니다.

## 화면과 가격 조정 — 2026-09-10

사용자 피드백에 따라 크림색·세리프 중심 UI를 하늘색·흰색·파랑과 굵은 산세리프로 바꿨습니다. 가게·공원 일러스트는 유지합니다. 음료 기본가는 3,000원이며 판매가·손님 지불 의향·원가·현금·목표·보관료·단체 대금을 모두 같은 비율로 3배 조정했습니다.

- 규칙 테스트 29개 통과: 기존 576개 경로의 보존 조건, v1/v2 이전, 추가한 v3의 3장터×3설비 모든 단계·완주·간판 기록 이전과 v4 재저장 시 중복 환산 방지
- 프로덕션 빌드 및 로컬 전체 브라우저 스모크 통과: PC·모바일, 세 장터, 메뉴·보관·선불 주문, 이어하기·키보드·모달·감사 스크롤
- 화면 캡처에서 준비·정산·가격 버튼·예약·설비·감사 화면의 대비와 모바일 가로 넘침을 확인했습니다.
- 실제 재미와 경제 이해는 아직 관찰하지 않았습니다. 사용자 결정에 따라 테스터를 모은 뒤 별도로 진행하며 초기버전 배포를 막는 조건이 아닙니다.

아래 배포 링크와 자산 이름은 이전 기능 출시 당시의 기록입니다.

### 키보드 조작 보완

수량 입력 후 Tab을 누르면 초점이 BODY로 빠지고 다음 Tab이 상단 도움말로 돌아가는 문제를 공개 버전에서 재현했습니다. 기존 입력 검증은 Tab 뒤 마우스로 버튼을 눌러 이 초점 문제를 놓쳤습니다.

- 수정: 수량을 확정한 뒤 새 화면의 다음 조작으로 이동합니다. Shift+Tab은 반대 방향으로 이동하고, 최솟값·최댓값에서 비활성 버튼은 건너뜁니다. 빈 입력은 기존 수량으로 복원하고 이동을 이어갑니다.
- 추가 검증: 8잔 입력 → Tab → 늘리기 → Space, 최대 12잔에서 비활성 늘리기 건너뛰기, 0잔에서 Shift+Tab 이동, 빈 입력 복원과 이동을 확인했습니다. 모바일에서는 초점 버튼이 화면 안에 보임을 캡처했습니다.

## 개발자의 게임성 판단

첫 판의 조작은 수량 하나로 시작합니다. 다음 장소에서는 가족과 공연 관객의 다른 가격 반응, 비용이 오르거나 내려가는 시점, 설비 자리의 기회비용, 단체 판매와 일반 손님의 진열 여유가 다른 선택을 만들었습니다. 새 메뉴가 모든 조건에서 손해였던 초기 수치를 수정하고 산책객의 차 선호를 선택 전에 알리도록 했습니다.

이 판단과 최적 경로 계산은 실제 재미를 입증하지 않습니다. 세 고정 조건을 외우면 소진될 수 있고, 후반 준비 패널의 정보량도 실제 플레이로 확인해야 합니다. 조작·규칙이 완결된 초기버전과 장기 숙련·학습 효과 검증을 구분합니다.


## 감사 스크롤 이스터에그 — 2026-09-10

사용자가 제공한 인사 GIF를 감사 스크롤 끝에서만 불러와 재생하도록 추가했습니다. 원본과 재생본 모두 122프레임·10fps·12.2초입니다. 처음부터 스크롤, 닫기, 재진입, 화면 밖 이동과 동작 감소 설정에서 재생 상태가 정리됩니다. 게임 저장은 바꾸지 않습니다.

- `npm test`: 29개 통과. `npm run build`: 통과.
- `npm run test:smoke`: 기존 영업·저장·장터·모바일·시간 동의와 새 이스터에그 검증 통과.
- 최초 숨김·URL 미연결, 끝 도달 후 실제 영상 시간 증가, 동작 감소 시 직접 재생, 위로 스크롤 시 정지, 다시 열기와 처음부터 스크롤 시 숨김, 완료 기록 보존을 확인했습니다.
- 화면 확인: `/tmp/good-afternoon-easter-qa/40-mobile-easter-egg.png` (390×844), `41-desktop-easter-egg.png` (1440×1000). 큰 재생바를 제거하고 작은 재생·멈춤 버튼을 사용합니다. 영상과 고정 진행 버튼이 겹치지 않습니다.

공개 주소 `https://jinhoops.github.io/good-afternoon/`에서도 같은 브라우저 검증을 통과했습니다. 영상 해제 시 해당 MP4 요청의 `net::ERR_ABORTED`는 의도한 다운로드 취소로 분류합니다. 다른 요청 실패와 콘솔 오류는 계속 실패 처리하며, 실제 디코딩·재생 시간 증가·정지 동작은 별도로 확인합니다. 공개 화면 캡처는 `/tmp/good-afternoon-easter-public-qa/`에 남겼습니다.
